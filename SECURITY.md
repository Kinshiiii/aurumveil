# Security Policy

## Supported Versions

This project is developed as part of an academic assignment and does not maintain multiple stable versions.

Only the latest version available on the `main` branch is considered supported.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by contacting the authors directly.

You can:
- open a private issue (if enabled), or
- contact the maintainers via email or GitHub.

We aim to respond within a few days.

Please include:
- a clear description of the issue,
- steps to reproduce,
- potential impact.

Note: This is an academic project and may not receive immediate security updates.
